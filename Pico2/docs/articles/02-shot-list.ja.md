## どの状態の基板をいつ撮るか

第1回と同じく、机はただ配線済みのまま座っているわけではない — オペアンプの
差し替えで1回、2つの抵抗の間違いの再現で2回、意図的に状態が変わって、また戻る。

| カット | 状態 |
| --- | --- |
| B2 (1:15) | **バラのパーツ** — 何も組んでいない。 |
| B3 (3:05) | **LM358 実装**、生成器の生キャリアを AC チャンネルに配線。 |
| S4 (3:05) | **MCP6022 に差し替え。** これ以降の全カットは MCP6022 を使う。LM358 はもう戻らない。 |
| B1 (0:00 / 1:15) | MCP6022 実装 — 定常状態。「ブレッドボード」が要る場面はどこでもこれを使い回す。 |
| B4 (4:05) | **100 Ω が正しい位置** — プラグの tip–sleeve 間。 |
| B5 (5:10) | **100 Ω を移動** — オペアンプの入力側へ、2つ目の失敗を再現。撮ったら**すぐ** B4 に戻す。以降のカットに持ち越さない。 |
| S8 / B6 (7:10) | **生成器の RC が 100 kΩ**（本来は 1 kΩ）。マクロ（B6）とスイープ（S8）は同じ状態のまま、カメラを動かさずに一度に撮ってから、1 kΩ に戻す。 |
| S8b (7:10) | **生成器の RC が 1 kΩ に戻っている** — 戻した机か、第1回の既存映像のどちらか。 |
| B7 (8:40) | **別の基板** — PL2407AFE。このカットまで机に出さない。 |

## 撮る順番

1. まず B2。パーツがまだバラで、いかにも未組み立てに見えるうちに。
2. LM358 で組む。B3 と S3 をカメラを動かさず一緒に撮る。
3. MCP6022 に差し替える。S4、続けて B1・S1（コールドオープンは B5 まで机が
   変わらないので、ここからいつ撮ってもよい）。
4. プラグに 100 Ω を正しく配線。B4、S5、S6 を撮る。
5. 100 Ω を間違った側へ移して B5 を撮り、すぐ元に戻す。
6. 生成器の RC の抵抗を 100 kΩ に差し替える。B6 と S8 を一緒に撮ってから
   1 kΩ に戻し、S8b を撮る（または第1回の映像がそのまま繋がるか確認する）。
7. S7（抜き差し）と S2（分圧の比較）は、AC チャンネルが正しく配線済みなら
   いつでも撮れる — 手順4以降ならいつでも。
8. S9（シミュレータ）と S10（締め）は実機の机が要らない。他の画面録画と
   一緒に撮る。
9. B7（PL2407AFE）は最後、それまで机に出さない。
