# 第1回 — 撮影リスト

英語版は [01-shot-list.md](01-shot-list.md)。内容は同じで、こちらが現場で使う方。

素材は2種類だけ。**画面**はアプリかWebページの録画、**実写**はハードウェアに
カメラを向けたもの。それ以外は要らない — Bロールも素材集も不要。

時刻はスクリプトのセクション位置であって、約束ではない。

## 画面録画

ディスプレイのネイティブ解像度で録り、**あとからウィンドウサイズを変えない**。
各カット長めに録って、編集で切る。

| # | カット | 使う場所 | メモ |
| --- | --- | --- | --- |
| S1 | 既に動いている波形、画面いっぱい | 0:00 コールドオープン | 動画の最初の1フレーム。プロット領域だけに切り抜く — メニューバーもDockも入れない。 |
| S2 | スコープ → スペアナ → ロジック → ロガー とクリックで巡回 | 0:25 | ゆっくり一周、各モードで一拍。 |
| S3 | GitHub のページ | 0:40 | 2秒。スクロールしない。 |
| S4 | 実際の接続：挿す → ページを開く → Connect → ブラウザのデバイス選択 → Run | 0:55 | **ワンテイク、カット無し。** デバイス選択ダイアログが肝 — 許可はこれ一つだけ、という話なので。 |
| S5 | フラットな線、そのまま保持 | 1:20 | 退屈に見えないといけない。5秒でも長すぎない。 |
| S6 | 信号生成をオン、サイン波が現れる瞬間 | 1:35 | 「出た後」ではなく**現れる瞬間**を撮る。 |
| S7 | スペアナに切り替え、440 Hz のピークが落ち着くまで | 1:55 | 落ち着くところまでカメラを回しておく。 |
| S8 | バイアスの点線をオン・オフするパネル | 3:30 | **この回で一番重要なカット。** |
| S9 | チャンネル下のゲイン補正の表示 | 4:00 | 寄るのは編集で。アプリ側で拡大しない。 |
| S10 | RC無しの生キャリア — グチャグチャな波形 | 4:45 | S11 と**同じウィンドウ位置**で。並べて切るため。 |
| S11 | 同じ入力を 1 kΩ + 10 nF 経由で — 綺麗なサイン波 | 5:00 | pp の数値 3.15 V を見せる。 |
| S12 | チャンネルを増減させたときのレート表示 | 5:45 | 495k → 247k → 165k。3つ全部出す。 |
| S13 | Android スマホで USB-C 接続、ページが動いている | 2:05 | スマホ側で画面録画できるならそれ。無理なら実写（B7）で代替。 |

## 実写

ルールは二つ、これで全部決まる。**光を当てて、無地の面に対して真上から撮る** —
白い紙に卓上ライトを反射させる方が、どんなカメラ設定よりも効く。そして
**必ず横位置で撮る**：縦で撮ると 16:9 に切ったときに被写体が消えるか、左右が
黒帯になる。スマホの横位置なら 4032 x 2268、4K に余裕で足りる。

基板はフレームに沿わせるか、15°ほど振ると図解ではなく写真に見える。余った
ケーブルはフレームの外に逃がさず、内側で緩く巻く。

| # | カット | 使う場所 | メモ |
| --- | --- | --- | --- |
| B1 | Pico 2 と USB ケーブルだけ、白背景、真上から | 0:15 引きのカット | 他には何も写さない。「これだけです」を語るカット。 |
| B2 | USB ケーブルを基板に挿す手元 | 0:55 | S4 と対にする。 |
| B3 | 生成器の4ピン、真上からピント合わせて | 4:15 | 編集でピン配置を重ねるので、基板の周りに余白を残す。 |
| B4 | 生成器ピンから入力へジャンパ1本 | 4:30 | 線の端から端まで目で追えるように。 |
| B5 | 抵抗とコンデンサを挿すところ | 4:50 | 手が写ってよい。挿す前のパーツも見せる。 |
| B6 | ロジック用ヘッダ — 抵抗8本とピンヘッダ | 6:15 | 「安上がりなのに」が話の主旨。 |
| B7 | 基板の横にスマホ、両方動いている | 2:05 | PC が無いことが分かる引き。 |
| B8 | ブレッドボード上のオペアンプ、浅い被写界深度で思わせぶりに | 6:45 | 次回予告用。あえて説明しない。 |
| B9 | サムネ用：波形の出ているパネル、その脇に基板とケーブル | — | 机が片付いた最後に撮る。 |

## どの状態の基板をいつ撮るか

「最初は素、あとはずっと配線済み」ではない。4:15 のセクションは**わざと素に
巻き戻して組み直す** — それがそのセクションの論の運びそのものだから。順に：

| カット | 状態 |
| --- | --- |
| B1 (0:15) | **素** — 基板とケーブルだけ、何も繋がない。 |
| B2 (0:55) | **配線済み** — 小さいブレッドボードに載せ、生成器ピンから入力へジャンパ1本、そこに 1 kΩ + 10 nF。デモに必要：1:35 のサイン波はこの RC を通って来る。 |
| B3 (4:15) | **素** — ピン配置を重ねるので、シルクの上に何も乗っていない方がいい。 |
| B4 (4:30) | **素 + ジャンパ1本だけ、RC 無し** — S10 のグチャグチャを出すための「わざと間違えた版」。 |
| B5 (4:50) | R と C を挿すところ。カメラの前で配線済みに戻る。 |
| B6 (6:15) | 配線済み。横にロジック用ヘッダ。 |
| B7 (2:05) | 配線済み — デモそのものにスマホを添える。 |
| B8 (6:45) | **別の**ブレッドボード。MCP6022 のミニ AFE で、どこにも繋がっていない。 |

なので **B4/S10 と B5/S11 はカメラを動かさずに一度に撮る**。同じフレームの
ビフォー・アフターだから。

B8 はこの回では一度も繋がらない。前のカットに写り込まないよう、最後まで机に
出さない。

配線状態のカットには基板にヘッダが要る。B1 が未はんだの新品ならその方が B1 と
しては綺麗 — **B1 と B3 をはんだ付けの前に撮って**、B2 以降はヘッダ付きの個体で。

## 録画の設定（macOS）

標準の録画機能で足りる。**⇧⌘5 →「選択部分を収録」**。ウィンドウ単位の収録モード
は無く範囲をドラッグする形だが、ここではその方が都合がよい：範囲を一度決めれば
全テイクが同じ切り抜きになるので、**S10 と S11 が編集で位置合わせ無しに繋がる**。

最初のテイクの前に、**オプション**メニューで：

- **最後の選択範囲を記憶** を**オン**。これが一番効く — テイク間で切り抜きが保たれる。
- **フローティングサムネールを表示** を**オフ**。付けっぱなしだと前のテイクの
  サムネが次のテイクに流れ込む。
- **マウスクリックを表示** は S4（ポインタの動きそのものが話になるところ）だけ
  オン、他はオフ。テイクごとに切り替える。
- **保存先**はデスクトップ以外のフォルダに。デスクトップが収録ファイルで埋まる。
- マイクは**オフ**。ナレーションは別録りで、尺も既に合わせてある。

周辺：集中モード（通知オフ）、Dock を隠す（⌥⌘D）、デスクトップアイコンを消す
（`defaults write com.apple.finder CreateDesktop false; killall Finder` — 後で
`true` に戻す）。時計を出したくなければ、収録範囲をメニューバーより下から取る。

Retina 解像度のまま記録されるので、2× ディスプレイのウィンドウなら編集で寄っても
甘くならない。**システム音声は録れない** — 今回は不要だが、後の回でアプリの音を
入れたくなったときのために覚えておく。

**S13（スマホ）だけ注意：** スマホの USB-C ポートは Pico が占有しているので、
ケーブル経由のミラーリングはできない。Android のクイック設定にある画面録画を使い、
同時に三脚で B7 を撮っておくと、画面と「PC が無い」証拠の両方が手に入る。

## テスト写真について

最初に撮ったベンチの写真（削除済み）は、実際の作業机が写っているという良さは
あったが、画としては3点で自滅していた：

1. **光量不足。** 全体が暗いビネットに沈み、暗い机の上に暗い基板が乗っている。
   この明るさだとスマホは ISO を上げるので、ノイズがシルクスクリーンを潰す。
   視聴者が一番読みたいディテールがそこなのに。
2. **斜めで、低い。** 机の向こう側から撮っているのでブレッドボードが菱形になり、
   列がどの辺とも平行になっていない。真上から、カメラを基板と平行にすれば
   配線が読めるようになる。
3. **四辺すべてから線が出ていく。** さらに、この回で一度も触れないスペアの
   ブレッドボード2枚とユニバーサル基板が写り込んでいる。目が散らかりの方へ行く。

直すのはタダ：写さないものを全部どける、A4 の白紙かカッティングマットを下に敷く、
卓上ライトを天井か壁に向けて光を柔らかくする、真上から基板の辺をフレームと平行に。
遊んでいる線はテープで留める。

あの写真から残す価値があるのは「ポーズではなく**使っている状態**を見せる」という
発想の方で、B7 と B8 が散らかりを除いてそれをやる。

## 撮る順番

1. 画面録画を**全部一度に**。アプリの設定とウィンドウ位置が決まっている状態で、
   テイク間でアプリを終了しない。
2. 机を片付ける。そのあと B1、B9。
3. 配線して B3〜B6 を、動画で組み立てる順に撮る。ハードはパーツが**増えるだけ**で、
   途中で減らさない。
4. 最後に B7、B8。
