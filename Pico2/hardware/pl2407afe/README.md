# PiLyzer for PL2407AFE

購入したpicoLABO **PL2407AFE + Raspberry Pi Pico 2** 用のPiLyzer構成です。
ScoppyのAndroidアプリやファームウェアのコピーではありません。基板のAFEを利用し、PiLyzerのmacOS／Webアプリで測定します。

## 構成

- `board_config.h`: PL2407AFE専用GPIO・2ch・3レンジ換算値（board ID 3）。
  `../../firmware/pilyzer/board_config.h`がboard ID 3のときにこれを取り込みます。
- `build.sh`: 共通PiLyzerファームウェアをこの基板用にビルド。
- `tests/`: GPIO・レンジ・2ch取得の自動チェック。
- アプリは共通です。Webは[`../../Web`](../../Web)、macOSは`cd ../.. && ./Scripts/make-app.sh`。

アプリは接続したファームウェアから2ch・3レンジを取得します。既存Pico2用ファームウェアのビルド設定は変わりません。

## ビルドと書き込み

```sh
./Pico2/hardware/pl2407afe/build.sh
```

出力: `Pico2/hardware/pl2407afe/build/PiLyzer-PL2407AFE-Pico2.uf2`

Pico 2をBOOTSELで接続し、このUF2をコピーします。元のScoppyファームウェアは置き換わります。Scoppy Androidアプリへ戻す場合はScoppy用UF2を書き戻します。
このビルドはRP2350のPico 2用です。初代Pico/RP2040用ではありません。

## 配線・制御

| 機能 | GPIO |
|---|---|
| CH1 / CH2 | 26 / 27 |
| CH1レンジ制御 | 2, 3 |
| CH2レンジ制御 | 4, 5 |
| Logic D0–D7 | 6–13 |
| テスト出力（SG OUT） | 22（基板上1kΩ経由） |
| 信号生成器 | 16 サイン, 17 ホワイト, 18 ピンク, 19 ブラウン |

空きGPIOは 0, 1, 14, 15, 20, 21, 28 です。28だけがADC（ADC2）に繋がっています。
23/24/29はPico 2自身が使い、Pico 2 Wでは25も無線モジュール側に行きます。

テスト出力と信号生成器のピンは全ボード共通です。この基板のSG OUTが22にあり、
16–19が空いていたので、他のボードがそれに合わせました。PWMスライスも競合しません。
生成器の各ピンはPWMキャリアなので、電圧として使うにはRC（1kΩ + 10nF）が要ります。
**起動時に16–19はLow出力として駆動されます**ので、基板側がこれらのピンに何か
繋いでいないかメーカー回路図で確認してください。

CH3のAFEはありません。AC/DCは基板上スイッチで操作します。
各CHの制御ピンをA/Bとすると、±30Vは00、±6Vは01、±1.5Vは10です。
レンジ切替時には一旦00に戻し、両方のバイパスを同時に有効にしません。

## 入力保護

**BNCから見た絶対最大入力電圧は ±40 V です（メーカー公称）。レンジ設定によらず
一律です。**

分圧がレンジ切替スイッチより前にあるからです。BNCは直結で 940 kΩ + 120 kΩ を
見ており、レンジ別の直列抵抗（24230 / 4230 / 330 Ω）はその後ろ、減衰済みの信号を
受ける位置にあります。**アプリからレンジを変えても、入力端の耐圧は変わりません。**

ここから導いた数字（公称値からの計算で、実測ではありません）:

| | 値 |
|---|---:|
| BNCが最初に見る抵抗 | 940 kΩ |
| ±40 V を加えたときの入力電流 | 43 µA |
| 分圧比（120 kΩ が対GNDのシャントとして） | 0.113 |
| ±40 V のときの分圧点 | 4.53 V |

43 µA では抵抗は焼けません。±40 V を決めているのは電流ではなく、**分圧点が
能動素子に見せる電圧**の方です。5 V 動作のオペアンプの絶対最大入力
（V+ +0.3 V = 5.3 V）には 47 V 前後で到達する計算で、±40 V という公称値と
整合します。超えたときに起きるのは抵抗が焼けることではなく、オペアンプか
アナログスイッチの入力に食い込むことです。**壊れ方が静かで気づきにくい**ので、
上限は余裕を持って扱ってください。

120 kΩ がシャントなのか基準電圧側なのかは未確認です。どちらであってもBNCが
940 kΩ で受けることは変わりません。

### 使うときの線引き

- **絶対最大定格は常用の上限ではありません。**±30 V レンジに対する余裕は
  1.33 倍しかなく、リレーやモーターの逆起電力、電源投入時のリンギング、車載
  12 V 系のロードダンプ（40〜100 V に達します）を吸収できません。±30 V レンジは
  「30 V を測るため」ではなく「20 V くらいまでを安心して測るため」と考える方が
  安全です。
- **絶縁はありません。**GNDはUSB経由でホストの筐体に繋がっています。
- **商用電源は測れません。**100 V ACはピーク141 V、絶対最大の3.5倍です。
- ×10プローブを使えば入力は1/10になりますが、**プローブ自体の耐圧が足りている
  場合に限ります**。パネルのプローブ倍率も忘れずに合わせてください。

参考までに、自作の[PiLyzer AFE](../pilyzer-afe/README.md)は入力1 MΩで±25 Vレンジ、
連続100 V定格 ── 余裕が4倍あります。設計の狙いが違うので、そのつもりで。

## 電圧換算と検証状況

[メーカー回路図・説明](https://picolabo.org/pl2407afe/)のrev.1cを基準にしています。
rev.1dはメーカー説明上仕様変更なしですが、届いた基板のリビジョンと実測は未確認です。

公称抵抗値からのDC計算（アナログスイッチのオン抵抗・部品誤差は未補正）:

- 初段反転増幅器の利得は−0.1。
- 後段の基準電圧は `3.3 × 1 / 25 = 0.132 V`。
- レンジ別の直列抵抗Rsは24230 / 4230 / 330 Ω。
- `gain = 1.2 / (1 + Rs/1000 + Rs/10000)`。
- `offset = 13×0.132 − 12×(0.132/10000)/(1/Rs + 1/1000 + 1/10000)`。
- `Vinput = (Vadc − offset) / gain`。

ADC電源基準とAFE電源の差、抵抗誤差、スイッチ抵抗があるため、各CH・各レンジで0Vと既知電圧を確認し校正してください。最初はDC結合・±30VレンジでGND、続いて既知の小さい信号を確認します。
AFEの帯域はADCサンプリング速度とは別です。このファームウェアはADCをオーバークロックせず、1ch約495kSa/s、2ch約247kSa/sです。

**基板は到着済みですが、USB実機での測定・レンジ切替・校正はまだ実施していません。**
上の換算値は公称値からの計算のままです。

## 自動チェック

`./Pico2/hardware/pl2407afe/tests/run.sh`でGPIO・各レンジのADC範囲・2ch取得とCH3拒否を検証します。共通ファームウェアの回帰テストは`./Pico2/firmware/pilyzer/tests/run.sh`です。
